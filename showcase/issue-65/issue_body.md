## 📋 Project Overview
> **Board:** Raspberry Pi 4 Model B (4 GB, BCM2711 Cortex-A72 @ 1.8 GHz)

This project turns a Raspberry Pi 4 into a whole-home energy intelligence hub: four split-core SCT-013 CT clamps slip onto mains wiring without any rewiring, their tiny AC voltages are conditioned by burden resistors and read through an ADS1115 16-bit ADC over I2C at up to 860 SPS, and the Pi 4's quad-core Cortex-A72 computes per-circuit RMS current, real power (W), and cumulative kWh 24/7 without breaking a sweat. Historical data lands in a local InfluxDB 2.x time-series database and is visualised in a Grafana dashboard with hourly, daily, and monthly roll-ups — letting users pinpoint vampire loads and correlate them with utility bills at a glance. An optional RS-485 add-on module paired with `modbus_solar.py` reads live telemetry from any EPEver/SRNE/Renogy-compatible MPPT solar charge controller, so panel generation is overlaid against household consumption for real net-metering arithmetic. Automation rules in Node-RED can fire MQTT commands — dimming smart plugs, deferring washing machines to off-peak tariffs, or pushing Telegram alerts when daily spend exceeds a threshold. The entire stack (Mosquitto, InfluxDB, Grafana, Node-RED) installs in one command via `setup.sh`, and a `systemd` service keeps the monitor running across reboots.

## 🧰 Key Components & Peripherals
- Raspberry Pi 4 Model B (2 GB or 4 GB recommended)
- **4×** SCT-013-030 split-core CT clamps (30 A non-invasive current sensors)
- ADS1115 16-bit I²C ADC breakout (Adafruit / AZDelivery)
- 62 Ω burden resistors + 10 µF electrolytic capacitors (signal conditioning)
- MAX485 RS-485 ↔ UART module (for optional solar Modbus integration)
- MicroSD 32 GB+ (Class 10 / A2 rated)
- Optional: 5V/3A USB-C power supply with UPS HAT for uninterrupted monitoring
- Optional: MPPT solar charge controller with RS-485 port (EPEver, SRNE, Renogy)

## ⚡ Quick Start

```bash
# 1. Enable I2C on the Pi 4
sudo raspi-config   # → Interface Options → I2C → Enable

# 2. Clone this repo and enter the project
git clone https://github.com/SRECONICS/SRECONICS.git
cd SRECONICS/showcase/issue-65

# 3. Install full stack (Mosquitto, InfluxDB, Grafana, Node-RED)
chmod +x setup.sh && sudo ./setup.sh

# 4. Edit the generated INFLUX_TOKEN in energy_monitor.py, then run
python3 energy_monitor.py

# 5. Open Grafana dashboard
# http://<pi-ip>:3000   (default: admin / admin)
```

> **Safety note:** CT clamps are non-invasive — they clip around a single conductor *outside* your consumer unit. No live wiring contact is needed. Always confirm mains wiring is de-energised before opening panels.
